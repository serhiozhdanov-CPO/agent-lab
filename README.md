# agent-lab

Стенд для проверки аналитики здоровья на синтетических данных.

Генератор выпускает 16 недель суточных записей о здоровье и режиме, в которые заранее
заложены известные закономерности. Аналитику, которую проверяют на этих данных, можно
оценивать объективно: что она обязана найти, записано заранее и проверяется автоматически.

## Три документа, в порядке чтения

| Файл | О чём |
|---|---|
| [`expected-patterns.md`](expected-patterns.md) | Восемь паттернов, заложенных в данные: гипотеза, механизм, ожидаемый эффект в числах, критерий обнаружения и то, чем ошибётся наивный анализ |
| [`canonical-format.md`](canonical-format.md) | Формат, в который пишет слой приёма, и семь решений, которые он фиксирует; контракт адаптера |
| `synth/` | Реализация: канонический слой, контракт адаптера и генератор как первый адаптер |

## Быстрый старт

Зависимостей нет — только Python 3.11 и стандартная библиотека.

```bash
python -m synth.cli --age 38 --weeks 16 --seed 42 --out data/

python tools/validate.py data/synth-0001/observations.jsonl   # соответствие формату
python tools/check_patterns.py data/synth-0001/               # PASS/FAIL по P-01…P-08
```

Один seed даёт побайтово один и тот же файл. Возраст задаётся параметром, и от него
считаются базовые линии пульса покоя, вариабельности, максимального пульса и потребности
во сне.

## Что получается на выходе

```
data/synth-0001/
  observations.jsonl   поток наблюдений в каноническом формате
  manifest.json        паспорт набора: субъект, период, seed, покрытие метрик
  ground_truth.json    ключ ответов: заложенные события с ID паттернов
```

`ground_truth.json` вынесен отдельно намеренно: по нему аналитику можно **оценивать**,
но нельзя, чтобы она в него **заглядывала**. Частью канонического формата он не является —
у реальных адаптеров такого файла нет и быть не может.

## Архитектура

Генератор — не самостоятельный скрипт, а **адаптер слоя приёма**:

```
Apple Health ─┐
WHOOP ────────┼─→ адаптер ─→ [ канонический формат ] ─→ хранилище ─→ аналитика
кольцо Сбера ─┤
synth ────────┘
```

Он реализует тот же контракт (`synth/adapters/base.py`) и пишет тот же формат, что позже
будут реализовывать адаптеры Apple Health, WHOOP и кольца Сбера. Отличается только тем, что
источник данных у него не устройство, а модель, — а значит, известен наперёд.

## Правило изменений

Карточка паттерна в `expected-patterns.md` и код генератора меняются одним коммитом.
`tools/check_patterns.py` исполняет критерии из карточек, поэтому разошедшийся документ
сразу делает проверку красной.
